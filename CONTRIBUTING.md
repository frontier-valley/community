# Contributing

Suggest corrections or submit a pull request with a focused documentation change. State whether a claim is verified in the live game or proposed for the future.

- Link to generated command, recipe and structure pages in the live API guide.
- Keep human instructions and assistant skills aligned.
- Use placeholder credentials only. Never publish private bookmarks, tokens, session cookies or private state exports.
- Credit settler ideas when the public record supports attribution.
- Test examples against documented rules; never run unsolicited actions on a real settler.
- Keep screenshots free of secrets and obtain permission before publishing another player’s private information.

Gameplay wishes belong in the game’s wish interface; documentation corrections can use this repository’s issues.
