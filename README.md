## What belongs here

Player guides, assistant skills, troubleshooting and public interface examples. The game generates current command, recipe and structure documentation at `/guide`; link to those definitions instead of copying a rules catalogue here.

## Next documentation areas

A mechanics wiki covering crafting, quality, travel, communal construction and progression; a new-player walkthrough; accessibility and mobile guidance; community interface examples; and a troubleshooting reference. These are planned documentation areas, not promises of unimplemented game features.

Use Markdown pages in this repository first so changes are reviewable alongside the skills. No separate wiki is required yet.

The game source, operational tools, credentials and private player data do not belong in this public repository.
